# Mini Centro de Tickets

Aplicación web desarrollada con React + TypeScript para gestionar tickets de soporte.

## Funcionalidades

- Listado de tickets.
- Filtro por estado.
- Crear nuevos tickets.
- Resolver tickets abiertos.
- Estados de carga y error.
- Validación con Zod.
- Test unitario con Vitest.

## Tecnologías

- React
- TypeScript
- TanStack Query
- Zod
- Vitest
- Vite
